# 品質チェック（QC）

**セクション単位QC（Step 8）での運用ルール**: そのセクションに**存在しない技術要素の項目はスキップしてよい**（例: JSの無いセクションはJS項目、画像の無いセクションは画像項目、SCSS不使用案件はSCSS項目）。ただしスキップは「要素が存在しないから」のみが理由になる——「たぶん大丈夫だから」でのスキップは禁止。存在する要素の項目は必ず1項目ずつ突き合わせる（全体QC＝Step 9では全項目を対象にする）。

## QCの心得

- 余白・寸法はデザインを**測って、測った値をそのまま書く**。測った値から離れた値を書くときは理由を式でコメントに残す（例: `実寸40 − はみ出し24.5 = 15.5`）
- 「たぶん同じ」「ほぼ見えないから大丈夫」と思ったら、その自己判断が事故のもと。測って、並べて、確認してから進む
- 細かい装飾（罫線・アイコン・字間・折り目）は**拡大して**確認する。等倍の目視では見逃す
- チェック項目がすべて○でも、最後に必ず自分の目でデザインと見比べる

## 1. 最優先チェック（MUST）

### ファイル管理

- [ ] グローバルスタイルを重複させていないか（2回目以降）
- [ ] 既存コードを削除・変更していないか

### UI状態切り替えボタン

- [ ] ハンバーガーメニューを2つのボタンで実装していないか
- [ ] ドロップダウン・アコーディオンを2つの要素で実装していないか
- [ ] 状態切り替えは1つの要素 + CSS/JavaScriptで実装されているか

### テキストの正確性

- [ ] すべてのテキストが1文字1文字一致しているか
- [ ] 絵文字・記号が正確に記録されているか
- [ ] 改行位置がデザイン通りか
- [ ] テキストの順序（上下・左右）が正確か
- [ ] 見出し構造（例: 上に日本語、下に英語）が正確か
- [ ] 推測・意訳・言い換えをしていないか

## 2. 必須チェック（REQUIRED）

### z-index管理

- [ ] position指定時にz-indexを設定しているか
- [ ] z-index値が論理的な階層に従っているか（10刻み）
- [ ] 99999のような過剰な値を使っていないか
- [ ] 装飾疑似要素（absolute）に z-index: -1、親に position: relative + z-index: 0 のセットがあるか

### :focus-visible

- [ ] すべてのインタラクティブ要素に:focus-visibleが設定されているか

### transition明示

- [ ] transition: allを使っていないか
- [ ] 必要なプロパティを明示的に指定しているか
- [ ] hover で変化させるプロパティに、要素側の transition がセットで書かれているか

### any-hover

- [ ] hover効果を`@media (any-hover: hover)`で囲んでいるか

### 余白の方向

- [ ] config.mdの余白設定に従っているか
- [ ] 異なる種類の要素間の余白に gap を使っていないか（**縦横を問わず**。アイコン＋テキストの横並び等も margin を使用すること）
- [ ] gap を使っているのは同じ要素の繰り返しで間隔が均等な場合（カードグリッド、ナビリンク等）のみか
- [ ] 上下同値 → margin-block使用しているか
- [ ] 左右同値 → margin-inline/padding-inline使用しているか
- [ ] セクション間の余白が padding-top 側で管理されているか（padding-bottom の単独使用は「帯内側の下端」等の正当な理由があるか）
- [ ] 帯（背景付きセクション）の端の余白を帯自身の padding-block が持っているか（子要素に分散させていないか）
- [ ] :first-child での margin 打ち消しをしていないか（繰り返しブロックは親の gap 一元管理へ）
- [ ] padding ショートハンドの制限を守っているか（4辺同値の1値のみ。2値以上は padding-block / padding-inline。`padding-block: 0 X` の0埋め禁止）
- [ ] margin: 0 auto を書いていないか（margin-inline: auto を使う）
- [ ] 背景のない要素同士の余白を padding で取っていないか

### レイアウト制御

- [ ] すべてのセクションで`.inner`が適切に使用されているか
- [ ] `.inner`の入れ子になっていないか
- [ ] `.inner` を文脈セレクタ（`.section .inner`）で上書きしていないか（マルチクラス `class="inner section__inner"` で上書きしているか）
- [ ] 全幅が標準と異なるセクションに専用 inner を与えているか（標準 inner に押し込んでいないか）

### 配置・整列

- [ ] 見出し・ボタンの位置がデザインと一致しているか
- [ ] カード・アイテムの配置がデザインと一致しているか
- [ ] SP版とPC版で適切に切り替わっているか

### 背景・色

- [ ] セクション・カード・テキストの色がデザインと一致しているか
- [ ] すべての色が変数を経由しているか（HEX直書きが残っていないか）
- [ ] 近似値を既存変数にまとめていないか（一致しない色は新しい変数を追加したか）
- [ ] 線で描かれた装飾を CSS 近似せず SVG で置いているか。斜め・多段グラデを CSS で書いていないか（縦横の単純グラデのみ可）

### ボタン・リンク

- [ ] 文言が1文字1文字一致しているか
- [ ] 絵文字・記号を勝手に追加していないか
- [ ] 枠線・背景色がデザインと一致しているか
- [ ] 外部リンク（別ドメイン）に rel="noopener noreferrer" を付与しているか
- [ ] 内部リンクに不要な target="_blank" を付けていないか
- [ ] tel: リンクに PC 発信無効化（pointer-events: none）があるか

### 画像

- [ ] width/height属性を付与しているか
- [ ] loading="lazy"を付与しているか
- [ ] alt属性を適切に設定しているか
- [ ] コンテンツ画像・装飾画像には loading="lazy" を付与しているか
- [ ] FV（ファーストビュー）内の画像には loading="lazy" を付けていないか（初期表示が遅くなるため）
- [ ] FV主画像に fetchpriority="high" の付与を検討したか
- [ ] <source srcset="*.webp"> を書いた画像の .webp ファイルが images/ に実在するか（Glob で確認）
- [ ] ローカル画像がセクション別フォルダ（images/セクション名/セクション名-連番）に置かれているか。サイト共通画像は images/common/ か

### セマンティックHTML

- [ ] section, article, nav等を使用しているか
- [ ] 連絡先情報（住所・電話・メール）を <address> でマークアップしているか
- [ ] 画像＋キャプションの組み合わせを <figure> + <figcaption> でマークアップしているか
- [ ] 日付を <time datetime> でマークアップしているか
- [ ] 運用で増減するコンテンツ（注釈・リスト等）が1項目1タグ + 親gap になっているか（br連結していないか）

### 見出し構造

- [ ] <h1> がページに1つだけか（0個・複数はNG）
- [ ] 見出しレベルをスキップしていないか（例: h2の次にh4を使わない）
- [ ] すべての <section> に見出し（h2〜h6）があるか。見出しの無い塊は <div> にしているか
- [ ] TOPページの h1 がロゴ（サイト名）か。下層ページの h1 がページタイトルか
- [ ] キャッチコピーを見出しタグにしていないか（<p> で書いているか）
- [ ] title タグが命名規則どおりか（TOP=`サイト名 | キャッチ`、下層=`ページ名｜サイト名`）

### アクセシビリティ

- [ ] 画像にalt属性（装飾画像はalt=""）
- [ ] テキストのないボタン・リンクにaria-label
- [ ] 装飾アイコンにaria-hidden="true"
- [ ] アイコンを絵文字で実装していないか
- [ ] コントラスト比が WCAG AA（通常テキスト4.5:1 / 大きい文字3:1）を満たしているか
- [ ] タップ要素（ボタン・リンク）が実寸44×44px以上か
- [ ] フォーム要素に <label> が for/id 一致で関連付いているか

### letter-spacing

- [ ] letter-spacingがem単位で記述されているか（px直指定は禁止）
- [ ] デザイン上のpx値をfont-sizeで割った正しいem値になっているか

### メディアクエリ配置

- [ ] メディアクエリがセレクタ直後に配置されているか
- [ ] ファイル末尾にメディアクエリをまとめていないか

### レイアウト手法

- [ ] 横並びの要素にflex/gridを使用しているか
- [ ] 縦に積まれるだけの要素に不要なflex/gridを使っていないか（通常フロー + margin で済む場合）
- [ ] absoluteが装飾・重ね表示以外の目的で使われていないか
- [ ] display: grid に grid-template-columns が明示されているか（暗黙の単列 grid がないか）
- [ ] 同じ値の繰り返しに repeat() を使っているか
- [ ] 2カラム以上の横並びが%換算されているか（固定pxで中間幅にはみ出さないか）。ボタンを%化していないか
- [ ] 内容幅のボタン列の flex 行に flex-wrap: wrap があるか（固定幅+nowrap の列には付けていないか）
- [ ] !important・IDセレクタでスタイルを当てていないか
- [ ] ブロックの寄せが親に1回で書かれているか（子への重複指定・他要素の幅を写した固定widthがないか）

### タイポグラフィ

- [ ] テキスト要素に font-size / font-weight / color / line-height の4つが指定されているか
- [ ] body に letter-spacing を指定した場合、大きい見出しに em で再指定しているか。字間0が正の要素に明示しているか
- [ ] 1行に収めたいテキストの幅に数pxの余裕があるか（末尾字間の超過による段落ち防止）

### SCSS（config.mdでSCSS指定時のみ）

- [ ] @importを使用していないか（@useを使用しているか）
- [ ] SCSS指定時: SCSS変数（$）を使用しているか（CSS変数 var() ではなく）
- [ ] CSS指定時: CSS変数（var()）を使用しているか
- [ ] Sassネストが BEM 要素（&__xxx）に使われていないか（疑似要素 &::before や疑似クラス &:hover はOK）
- [ ] 色は「色型」（#hex や色名）で定義しているか（config.md で SCSS/Sass 指定時のみ適用）
- [ ] 色を RGB の数値リスト（例: `255, 255, 255`）で定義していないか
- [ ] 透明度は `rgba($color, $alpha)` の第2引数で表現しているか

### 命名規則（config.md設定に従う）

**FLOCSS時:**
- [ ] c-（Component）、p-（Project）、l-（Layout）、u-（Utility）の接頭辞
- [ ] BEM記法（__,--）と接頭辞の併用
- [ ] 接頭辞なしBEM（service__card等）を使用していないか

**BEM時:**
- [ ] 接頭辞なしのBEM記法のみか
- [ ] is-/has-状態クラスを使用しているか

### JavaScript

- [ ] console.log／デバッグ出力を残していないか
- [ ] JS からの参照に js- フック、状態表現に is-/has- を使っているか（スタイル用クラスをJS参照に流用していないか）
- [ ] var を使っていないか（const 優先、再代入が必要なときのみ let）
- [ ] 比較は ===・!== を使っているか（==・!= は禁止）
- [ ] イベント登録は addEventListener を使っているか（inline onclick は禁止）
- [ ] クラス操作に classList を使っているか（className 直接書き換えがないか）
- [ ] ハンバーガー: closeDrawer 共通化・ドロワー内リンクで閉じる・matchMedia の PC幅対策（スクロールロック残留なし）があるか
- [ ] ハンバーガーボタンに aria-label / aria-expanded / aria-controls、ドロワーに aria-hidden があるか
- [ ] スライダーの breakpoints が CSS のブレークポイントと一致しているか

### マークアップ品質

- [ ] レイアウト目的（改行位置の調整）で <br> を使っていないか（余白・折り返しは CSS で制御）
- [ ] 装飾目的で本文と重複するテキストを、data-* 属性 + 疑似要素（::before/::after）に逃がしているか
- [ ] 疑似要素の content: attr() に読み上げ除外の `/ ""` が付いているか（装飾英字が唯一の見出しの場合を除く）

### script配置（head + defer 固定）

- [ ] <script> が <head> 内に defer 付きで置かれているか（</body> 直前に置いていないか）
- [ ] type="module" にも明示的に defer が付いているか
- [ ] CDN ライブラリも <head> 内 + defer か

### ビルド検証（config.md で ビルドツール:Vite かつ ビルド検証:ON のときのみ）

- [ ] npm run dev / npm run build が最後まで通るか（エラーなし）
- [ ] 新規追加した Sass パーシャルを _index.scss に @forward し忘れていないか
- [ ] ビルド時に Sass の警告（deprecation 等）が出ていないか

### レスポンシブ3幅検証（config.md で ブラウザQC検証:ON のときのみ）

- [ ] 375px / 中間 1000px / 1440px の**3点**で崩れ・はみ出しを確認したか（固定幅要素×%列の組み合わせは中間幅でだけはみ出す。SP/PC の2点チェックでは見逃す）
- [ ] SP でドロワーを開いたまま PC 幅へリサイズし、スクロールロックが残らないか

## 3. 納品前チェック（納品時のみ）

- [ ] 納品物に開発ファイル（sass/・ビルド設定・node_modules・.claude 等）を含めていないか（先方指定がある場合のみ同梱）
- [ ] 納品 CSS が非圧縮（先方コーダーが読める状態）か（圧縮は先方指定時のみ）
- [ ] プロセス由来のコメント（FB経緯・作業日・修正番号・旧実装への言及）を削除したか。コードから読み取れない制約・実測値の式だけ残す
- [ ] console.log / debugger を削除したか（JavaScript項目と重複するが納品時に再確認）
