# static-code 購入者導入ガイド（完全版）

static-code は、デザインカンプ（画像・Figma URL・.xd/.psd/.aiファイル）から HTML/CSS/JavaScript の静的コーディングを自動で行う Claude Code 用スキルです。本ガイドは、購入〜契約〜セットアップ〜日常利用〜サポート窓口〜トラブル対応までを一通り解説する、購入者向けの完全版マニュアルです。

対象読者: static-code を購入（またはAIクラフトラボ会員特典として利用開始）する方。

## 1. サービス概要とプラン

static-code は次の2つの提供形態があります。

| プラン | 料金 | 提供方法 |
|---|---|---|
| ①AIクラフトラボ会員 | 追加費用なし | 「AIクラフトラボ」受講料に含まれる特典として、ライセンスキーを発行 |
| ②月額サブスクリプション | 月額 30,000円 | Stripe決済（無料トライアルなし）。決済完了後にライセンスキーを即時発行 |

- コーディングのノウハウ本体（工程手順・構成ルールの詳細）はローカルには保存されず、実行のたびに static-code API サーバー（Google Cloud Run）から取得してその場で利用する方式です。手元に残るのは通信用のクライアントコードと、公開済みの基礎ルール（HTML/CSS/JS/QC/config）のみです。
- そのため、**利用にはインターネット接続とライセンスキーが必須**です。
- ライセンスは「1 ライセンスキー = 1 契約者・1 マシン」の制約です。

## 2. 購入〜契約の流れ

### ①AIクラフトラボ会員の場合

1. AIクラフトラボへの入会手続きを完了する（通常のラボ受講申込フロー）
2. ラボ運営（まさた）より、static-code のライセンスキー（`SL-XXXX-XXXX-XXXX` 形式）が発行・案内される
3. 本ガイドの「4. セットアップ手順」に進む

### ②月額サブスクリプションの場合

1. 申込ページからStripe決済を行う（クレジットカード決済、無料トライアルなし）
2. 決済完了後、登録したメールアドレス宛てにライセンスキー（`SL-XXXX-XXXX-XXXX`）が届く
   - 届かない場合は購入時のメールアドレスの入力ミス、または迷惑メールフォルダを確認する。それでも見当たらない場合は「7. サポート窓口」へ連絡
3. 契約は毎月自動更新（次回請求日の前に解約手続きを行わない限り継続課金）
4. 解約したい場合は次回請求日より前に手続きする（手続き方法は購入時の案内・Stripeカスタマーポータルを参照。詳細不明な場合はサポート窓口へ）
5. 本ガイドの「4. セットアップ手順」に進む

## 3. 前提環境

- Claude Code がインストール済みであること
- Python 3（標準ライブラリのみで動作します。追加の pip インストールは不要です）
- `.ai`（Illustrator）ファイルを扱う場合: Adobe Illustrator のインストール、および初回実行時の自動化（オートメーション）許可
- Figma URL を扱う場合: Figma MCP が Claude Code に設定済みであること
- **Claude Code 自体の利用契約（Claude Pro / Max または Claude API）は購入者ご自身で別途契約する必要があります。** 本サービスにはClaude Code自体の利用権は含まれません（当社はClaudeへのアクセスを代理提供・再販しません）

## 4. セットアップ手順

### 4-1. ライセンスキーを設定する

購入・入会時に受け取ったキーを以下のコマンドで設定します。

```bash
mkdir -p ~/.config/skill-license
echo 'SL-XXXX-XXXX-XXXX' > ~/.config/skill-license/license
```

`SL-XXXX-XXXX-XXXX` の部分は実際に受け取ったキーに置き換えてください。マシン識別用の `machine_id` は初回実行時に自動生成され、同じく `~/.config/skill-license/` に保存されます（自分で作成・編集する必要はありません）。

### 4-2. クライアントスキルを配置する

配布された `static-code.zip` を展開すると、`static-code` というフォルダができ、次の構成になっています。

```
static-code/                     （このフォルダごとスキルディレクトリへ置く）
├── SKILL.md
├── references/                  （html/css/js/qc/config）
├── client/                      （sc_client.py, sc_extract.py, ai2json.jsx）
└── README_FIRST.md              （このガイド。スキルの動作には不要なので、不要なら削除して構いません）
```

**展開してできた `static-code` フォルダを、そのまま Claude Code のスキルディレクトリ（`~/.claude/skills/`）の中に入れるだけ**です。Finder なら `~/.claude/skills/` の中へドラッグ＆ドロップ、コマンドなら次のとおりです。

```bash
# static-code.zip を展開したフォルダがある場所で実行
cp -R static-code ~/.claude/skills/
```

配置後は `~/.claude/skills/static-code/` に SKILL.md・references・client が入っていれば完了です（`README_FIRST.md` は残っていても動作に影響しません。不要なら削除して構いません）。

### 4-3. 権限（settings）の許可について

このスキルは `SKILL.md` の `allowed-tools` に、Bash（`python3` 実行のため）や Read/Write/Edit などを含んでいます。初回に `python3 client/sc_client.py ...` を実行する際、Claude Code から Bash 実行の許可を求められることがあります。その場合は許可してください。

毎回の確認を減らしたい場合は、Claude Code の設定（settings）で `python3` コマンドをあらかじめ許可（allowlist）しておくことができます。設定方法が分からない場合は Claude Code 側で「python3 コマンドを許可して」のように依頼してください。

### 4-4. セットアップ完了の確認

セットアップ後、Claude Code で「コーディングして」等と依頼してみて、エラーなくセッションが開始されればセットアップ完了です。エラーが出た場合は「8. トラブルシューティング」を参照してください。

## 5. 使い方（日常利用）

セットアップが終われば、通常どおりスキルを呼び出すだけです。

- デザインカンプ（画像・Figma URL・.xd/.psd/.ai）を渡して「コーディングして」「このデザインを実装して」のように依頼します。
- スキルが自動的にセッションを開始し、工程手順をサーバーから取得しながら進めます。ユーザー側でセッション管理やキーの受け渡しを意識する必要はありません。
- 抽出が必要な工程（.psd/.psb/.xd/.ai）では、内部で `client/sc_extract.py` が呼び出され、結果は従来どおり `.design-extract/` に展開されます。
- 一度抽出した案件は `.design-extract/` にキャッシュされるため、同じ案件で再度コーディングを依頼する際は再抽出が発生せず高速です。また、API障害時でもこのキャッシュがあれば作業を継続できます（詳細は「9. 障害時の考え方」）。
- 月間の抽出回数にはプランごとの上限があります。上限超過時は `429` エラーになります（「8. トラブルシューティング」参照）。

## 6. `.ai`（Illustrator）を使う場合の注意

`.ai` ファイルの抽出はローカルの Illustrator を自動操作して行われます。初回実行時に macOS から自動化の許可を求められるので、以下から許可してください。

- **システム設定 > プライバシーとセキュリティ > オートメーション**
- 「ターミナル（または実行環境）」から「Adobe Illustrator」への操作を許可する

許可しない場合、`.ai` の抽出は失敗します（トラブルシュートを参照）。

## 8. トラブルシューティング

| 事象 | 意味 | 対処 |
|---|---|---|
| セッション開始で `409` | 別のマシンで利用中（同一ライセンスキーが他マシンでセッション中） | 前のマシンでの作業終了から 60 分待って再試行してください |
| セッション開始で `403` | このライセンスキーは既に別のマシンに登録済み | PC を買い替えた等の理由がある場合は machine reset が必要です。サポート窓口（Discord の DM）に連絡してください |
| セッション開始で `401` | ライセンスキーが無効（未登録・入力ミス・失効済み） | キーの入力内容（`~/.config/skill-license/license`）を確認してください。解決しない場合はサポート窓口に連絡してください |
| セッション開始・抽出で `429` | 月次の抽出回数上限を超過 | プランの上限に達しています。翌月まで待つか、上限引き上げについてサポート窓口に相談してください |
| 「ライセンスキー未設定」 | `~/.config/skill-license/license` が存在しない、または空 | 「4-1. ライセンスキーを設定する」を再実行してください |
| `.ai` 抽出で Illustrator 操作が拒否される（TCC 拒否） | macOS のオートメーション許可が未許可、または以前拒否した | システム設定 > プライバシーとセキュリティ > オートメーションで許可を有効化し、再実行してください。改善しない場合は一度許可設定を削除して再度許可ダイアログを出し直してください |
| API に接続できない・サーバー障害時 | ネットワーク不通または API 側の一時的な障害 | 既に抽出が完了している案件（`.design-extract/` にキャッシュ済み）であれば、抽出済みデータを使ってコーディング作業自体は継続できます。新規の抽出やセッション開始が必要な工程は復旧を待ってください。復旧状況は障害時ポリシーのステータス通知先を確認してください |
| 決済したのにライセンスキーが届かない | メールアドレス入力ミス、迷惑メールフォルダ、配信遅延 | 迷惑メールフォルダを確認のうえ、届かない場合はサポート窓口に決済完了の証跡（Stripe領収書等）と併せて連絡してください |

## 9. 障害時の考え方

static-code は個人開発規模のサービスであり、SLA（稼働率保証）は設けていません。ベストエフォートでの運用です。詳細な取り扱い（24時間超障害時のサブスク日割り延長、ステータス通知方法等）は `docs/法務/障害時ポリシー_ドラフト.md` を参照してください。

要点のみ再掲します。

- 抽出済みの案件（`.design-extract/` にキャッシュがあるもの）は、API障害中でもコーディング作業を継続できます
- 新規の案件の抽出・新規セッション開始にはAPIへの接続が必要なため、障害中は実行できません
- 24時間を超える障害が発生した場合、サブスクリプション契約者には日割りでの延長対応を行います
